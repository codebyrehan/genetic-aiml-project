# Challenges in Regulating Genetic Information in Mammals

Genetic Algorithm & Machine Learning (AIML) - 1st Semester Project

## Project Overview
This project explores genetic algorithms and machine learning techniques for predicting genetic risks in mammals and discovering patterns through K-means clustering.

## Objectives
- Analyze genetic information in mammals
- Predict genetic risks using machine learning
- Discover genetic patterns using K-means clustering
- Understand challenges in genetic data regulation

## Files
- **`genetic_risk_predictor_mammals.py`** - Genetic risk prediction model using machine learning
- **`genetic_kmeans_discovery.py`** - K-means clustering for genetic pattern discovery

## Technologies Used
- Python
- Machine Learning (Genetic Algorithms)
- K-means Clustering
- Data Analysis
